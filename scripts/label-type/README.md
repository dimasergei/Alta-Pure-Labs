# PURE label lettering

`glyphs.json` contains outlines from the regular (400) and bold (700) instances of
Roboto Condensed. These outlines keep the small product and strength lettering
consistent when the standalone product SVGs are displayed as images. The PURE
brand wordmark is separately traced from the supplied packaging artwork; it does
not use this font.

Source: https://github.com/google/fonts/tree/main/ofl/robotocondensed

`RobotoCondensed.ttf` is the source variable font. See `OFL.txt` for its SIL Open
Font License. The source checksum is recorded in `glyphs.json`.

Product artwork is regenerated with `node scripts/generate-pure-product-assets.cjs`.
